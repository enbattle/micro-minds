# Architecture decision records

One file per genuinely non-obvious decision: what was decided, what
alternatives were considered, and why — a few paragraphs, not a
template-heavy document. This is what makes the project's judgment legible
to someone reading the code cold, instead of the reasoning living only in
chat history or a commit message.

Numbered sequentially (`0001-...`, `0002-...`), never renumbered or reused.
Each carries a status line: `Accepted` for a settled decision, or
`Provisional — pending Phase N finding` for one whose reasoning depends on
an open empirical question. Never let a record look more settled than it
actually is.
